# 한남랭 (HannamLang)

한글 감탄사/의성어만으로 구성된 난해한 프로그래밍 언어.

엄랭(umjunsik-lang)에서 영감을 받아 제작.

## 실행

```bash
python hannam.py examples/hello.한남
# 출력: HELLO World

python hannam.py --debug examples/countdown.한남
python hannam.py --ast examples/arithmetic.한남
python hannam.py --repl
```

## 키워드

| 키워드                 | 기능 |
|---------------------|------|
| `예? 저요?`            | 프로그램 시작 |
| `내아내임`              | 종료 + 반환값 |
| `엄`                 | 대입 (예: `ㅋ엄...` → var[1]=3) |
| `줴줴이야`              | 출력 (단독=정수, +값=유니코드) |
| `제가요?`              | 정수 입력 |
| `티~원`               | 개행 (`티~~원` = 2줄) |
| `요이`                | 줄 점프 |
| `ㅋㅋ..ㅋㅋ` / `아뇨아뇨아뇨` | 루프 (0=탈출, 0이외=계속) |
| `아뇨{값}?{명령}`        | 조건문 (값==0이면 명령 실행) |
| `쥐랄 이름` / `쥐랄ㅋㅋ`    | 함수 선언 |
| `어이 이름`             | 함수 호출 |
| `쥐~랄`               | == (같다) |
| `쥐~~랄`              | > (크다) |
| `쥐~~~랄`             | < (작다) |
| `쥐히랄`               | != (다르다) |

## 테이프 (Brainfuck 스타일) — 튜링 완전

30000셀 테이프 메모리. 포인터로 셀 접근.

| 키워드 | BF | 기능 |
|--------|-----|------|
| `드가재` | `>` | 포인터 → |
| `넌나가라` | `<` | 포인터 ← |
| `어흐` | `+` | 셀 +1 |
| `아흐` | `-` | 셀 -1 |
| `예에?` | `.` | 셀 ASCII 출력 |
| `예?` | `,` | stdin → 셀 |
| `ㅋ` | `[` | 루프 시작 (셀==0이면 탈출) |
| `ㅋㅋ` | `]` | 루프 끝 (셀!=0이면 계속) |

```
# 테이프로 "A" 출력 (8*8+1=65)
예? 저요?
어흐어흐어흐어흐어흐어흐어흐어흐
ㅋ
드가재
어흐어흐어흐어흐어흐어흐어흐어흐
넌나가라
아흐
ㅋㅋ
드가재
어흐
예에?
티~원
내아내임.
```

## 변수

`ㅋ` 반복으로 변수 지정: `ㅋ`=var[1], `ㅋㅋ`=var[2], `ㅋㅋㅋ`=var[3]

## 숫자

- `.` = +1, `,` = −1, `~` = 물결 카운트, 공백 = 곱셈
- `+`, `-`, `*`, `/`, `%` 연산자 지원
- 괄호 `()` 지원
- `예?` = stdin 정수 입력

```
...        => 3
.. ..      => 4 (2 × 2)
아 + ..    => var[1] + 2
(.. + ...) * .... => (2+3) × 4 = 20
```

## 카운트다운

```
예? 저요?
엄.....           # var[1] = 5
ㅋㅋ..ㅋㅋ         # 루프 시작
줴줴이야            # var[1] 출력
티~원
ㅋ엄ㅋ,            # var[1] -= 1
아뇨아뇨아뇨ㅋ     # var[1]==0 → 탈출
내아내임.
```
