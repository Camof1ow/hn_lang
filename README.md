# 한남랭 (HannamLang)

한글 감탄사/의성어만으로 구성된 난해한 프로그래밍 언어.

엄랭(umjunsik-lang)에서 영감을 받아 제작.

## 실행

```bash
python hannam.py examples/hello.한남
# 출력: H
```

## 키워드

| 키워드 | 기능 |
|--------|------|
| `예? 저요?` | 프로그램 시작 |
| `내아내임` | 종료 + 반환값 |
| `엄...` | 대입 (구두점≥3) |
| `줴줴이야` | 유니코드 출력 |
| `제가요?` | 정수 입력 |
| `티~원` | 개행 |
| `요이` | 줄 점프 |
| `ㅋㅋ..엄` / `아뇨아뇨아뇨` | 루프 |
| `아뇨{값}?{명령}` | 조건문 |

## 변수

`ㅋ` 반복으로 변수 지정: `ㅋ`=var[1], `ㅋㅋ`=var[2], `ㅋㅋㅋ`=var[3]

## 숫자

- `.` = +1, `,` = −1, `~` = 물결 카운트, 공백 = 곱셈

## Hello World

```
예? 저요?
엄........ .........
줴줴이야ㅋ
티~원
내아내임.
```
